# AyniteDM downloads

Public downloads and the website for **AyniteDM**, the download manager by AyniteSoft.

- Website: https://dev-hamxay.github.io/AyniteDM-releases/
- Latest installer: https://github.com/dev-hamxay/AyniteDM-releases/releases/latest

This repository holds only the landing page (`website/`) and the release files. The program's source is
maintained privately by AyniteSoft.
